# Configuración de red

## Objetivo

Configurar una dirección IP estática y verificar
la conectividad del servidor.

## Configuración

| Parámetro | Valor |
|---|---|
| IP | 192.168.20.2 |
| Máscara | 255.255.255.0 |
| DNS | 127.0.0.1 |
