# Laboratorio de Operaciones TI

## Objetivo

Implementar un entorno virtual para practicas en Linux y de administración
de sistemas Windows como gestión de usuarios, redes,
servicios y monitoreo.

## Tecnologías

- VirtualBox
- Windows Server
- Windows 10
- Windows 7
- Active Directory
- DNS
- DHCP
- GPO
- IIS
- CentOS
- Ubuntu
